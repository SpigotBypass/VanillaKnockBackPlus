# VanillaKnockBackPlus

Restore the **original 1.8.8 Minecraft knockback** on Spigot servers.  
Spigot slightly changed the knockback mechanics compared to pure vanilla, making PvP hits feel heavier and slower. **VanillaKnockBackPlus fixes that**, giving you the clean, smooth knockback you remember.  

[Check it out on SpigotMC!](https://www.spigotmc.org/resources/vanillaknockbackplus.129590/)

---

## Features

- Real **vanilla 1.8.8 knockback** physics  
- Simple config: choose **PvP-only** or **all entities**  
- Lightweight — zero lag or extra calculations  
- Works with **Spigot**, **Paper**, **TacoSpigot**, and forks  
- No dependencies or setup hassle
